<h1 style="color:blue">Braille board chess for the blind</h1>
<p>Braille Board Chess for the blind is an embedded systems projects developed by me @Snster146<br>
this project aims to make chess more intiuitve for the blind and visually impaired through a coordinate reading system and the use of braille</p>
<br>
<h2>How the project functions</h2>
<p>The project includes a physical product which can be manufactured woodwork or thorugh 3d printing, the 3d printing files are contained the branch BrailleBoard-V2. This includes the 3d models for the chess board and for each individual piece. <br>One problem you may have when printing the product and testing the pieces is that the pieces need to be of a certain weight to press on the switches without applying force therefore I reccomend pausing the print to add weights to each individual piece. I added small nuts into each piece. </p>
